# Notebook 活動・成果物抽出

高校の授業で生徒が編集した Jupyter Notebook (`.ipynb`) から、学習活動の指示・回答・コード・保存済み出力を抽出する **GitHub Pages 対応の静的Webアプリ**です。ブラウザ内だけで解析するため、Notebookをサーバーへ送信しません。

## 使い方

1. Webアプリ（`index.html`）を開き、提出Notebook単体またはフォルダを選択します。
2. 必要に応じて「編集前の正本」を別欄から読み込みます。正本がなければ活動・成果物を抽出し、あれば差分解析を追加します。
3. 生徒識別方法（ファイル名先頭の番号、ファイル名、親フォルダ名、手動）を選び、「活動・成果物を抽出する」を押します。
4. 生徒別・活動別ビューを切り替えて内容を確認します。不確かな追加セルは活動割り当てを修正できます。
5. 「採点用.ipynb」をダウンロードします。複数提出の場合はZIPで一括保存されます。

## 開発

追加のパッケージやビルド工程は不要です。リポジトリのルートを静的HTTPサーバーで公開してください（`file://` での JavaScript モジュール読み込みはブラウザの制限を受ける場合があります）。

```sh
python3 -m http.server 8080
# http://localhost:8080 を開く

npm test
```

### GitHub Pages

リポジトリの `Settings → Pages → Build and deployment` で `Deploy from a branch` と `main` / `/ (root)` を選べば、ルートの `index.html` が公開されます。`main` への更新を反映できます。複数人の提出物を公共のリポジトリにコミットしないでください。

### 構成

- `index.html` — 単一/一括取り込み、正本の任意登録、閲覧/ダウンロード
- `src/core.js` — Notebook検証、活動構造抽出、正本照合、差分処理
- `src/export.js` — 採点用Notebook出力、ZIPの生成
- `src/app.js` — 画面描画とファイル操作（画面へのHTML注入は禁止）
- `src/style.css` — デザイン
- `docs/SPEC.md` — MVP詳細要件と受入試験
- `tests/` — Node標準テストランナーで実行する回帰テスト

## 制約と注意

- **PythonコードはWebアプリでは実行しません。** ダウンロードしたNotebookの再実行時にはコードを確認してください。
- 元のコードセルはNotebook後半に元の順序で格納します。Colab・Jupyter・PyHirobaで折りたたみ表示が一致する保証はありません。
- `input()`で対話的に入力した値はNotebookに保存されていない場合復元できません。
- 正本なしでは「元ファイルから編集されたか」は確定できません。
- 頻繁なセル分割・統合、見出し全削除などに対して完全な照合を保証しません。曖昧な項目は確認が必要です。
- `src`内コードは依存ゼロ。ユーザーが選択したファイルを外部へ送信しません。CSP（Content Security Policy／コンテンツセキュリティポリシー）の `connect-src 'none'` で通信を禁止しています。
- 単体35MB、合計160MB、最大200件/回が初期制限です。ブラウザメモリ不足の可能性があるため大量提出では分割処理してください。
- 解析済みデータはページ更新で失われます。生成したファイルは都度ダウンロードしてください。
